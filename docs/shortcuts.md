# Keyboard Shortcuts

## Tab Navigation

| Shortcut | Action |
|---|---|
| `Ctrl+PageDown` | Next tab |
| `Ctrl+PageUp` | Previous tab |
| `Ctrl+1..9` | Jump to specific tab |
| `Ctrl+Shift+T` | Tab switcher (search tabs) |
| `Ctrl+W` | Close current tab |

## Terminal

| Shortcut | Action |
|---|---|
| `Ctrl+`` | Switch between Custom/Shell terminal |
| `F5` | Start/Stop project run |
| `Shift+F5` | Force stop project run |

## File Operations

| Shortcut | Action |
|---|---|
| `Ctrl+N` | Open new project (folder picker) |
| `Ctrl+E` | Open current folder in Explorer |
| `Ctrl+O` | Open file viewer (preview mode) |
| `Ctrl+Shift+E` | Open file viewer (edit mode) |
| `Ctrl+Shift+F` | Toggle file explorer panel |

## Panels & Popups

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+P` | Command palette |
| `Alt+G` | Git changes panel |
| `Ctrl+B` | Git branch switcher |
| `Ctrl+T` | Task panel (focus mode) |
| `Ctrl+Shift+N` | Scratch pad (notes) |
| `Ctrl+,` | Settings editor |
| `Ctrl+P` | Settings (Profiles section) |
| `F1` | Help |

## Default Quick Commands

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+C` | Commit (Claude Code) |
| `Ctrl+Shift+D` | Git Pull (Shell) |
| `Ctrl+Shift+U` | Git Push (Shell) |
